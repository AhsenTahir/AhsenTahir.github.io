SASD: Source-Aware Self-Distillation Prompt-injection resistance trained into the weights, not bolted on at inference In progress · targeting NeurIPS / ICLR

An agent reads retrieved pages, tool output and its operator's instructions through one undifferentiated channel, with nothing recording which span came from where. Existing defenses patch this at inference (a detector in front of the model, or delimiters around the untrusted region), and both give way to an attacker who rewords the payload.

SASD moves this into training. The student is optimized against a multi-teacher KL divergence objective where each teacher sees the same task under a different source condition, targeting the one for which the injected span was never present. Source tracking ends up in the weights, instead of a wrapper policing the model at run time.

Evaluating on prompt-injection benchmarks against the strongest current defenses, including adaptive attacks.

I am implementing the training stack and the injection benchmark suite. Happy to discuss the work directly.

When Agents Architect: Design-Level Security Anti-Patterns in LLM-Generated Microservice Systems Ahsen Tahir, Francis Palma, Shazil Khan In progress · University of New Brunswick

Work on LLM-generated code security measures line-level weaknesses such as CWEs inside single functions. Agentic tools now emit whole multi-service systems, so we ask whether those systems carry design-level security anti-patterns: flaws committed when the architecture is decided, not when a line is written.

We operationalize a catalog of anti-patterns from the microservice security-smells literature and build an agentic detector that indexes a repository, reconstructs its structural views, and returns a three-valued verdict per anti-pattern. The contribution is the unit of analysis (design patterns, not lines) and an agentic method where static analysis misses the class entirely.
